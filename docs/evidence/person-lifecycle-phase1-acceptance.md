# 人员状态同步第一期验收记录

## 适用范围

恒剑光电作为第一家用户；朱剑军作为管理员和总经理。人员状态由 M01 发起，EDP 负责分发，业务系统按统一合同办理。

## 验收步骤

1. 在 M01 搜索测试人员，确认姓名和工号。
2. 提交离职，确认办理人和审批人不是同一人。
3. 查看 M01、EDP 和每个已部署系统的进度。
4. 确认离职人员不再出现在在职名单，已离职名单能查询到本人。
5. 确认登录、审批、工作事项、设备和智能体清单已关闭或转为待交接。
6. 重新入职后，确认只恢复基本登录，原权限和智能体仍显示“待管理员确认”。
7. 重复提交同一事件，确认不会重复办理。
