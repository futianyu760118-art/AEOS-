# 人员状态同步操作流程

这份流程用于处理“离职”和“重新入职”。所有系统以 M01 为准，系统内的客户、订单、财务、质量、研发等历史记录不删除。

## 一键办理

1. 管理员登录 M01，打开“人员管理”。
2. 在搜索框输入姓名或工号，确认公司、部门和当前状态。
3. 点击“办理离职”或“办理重新入职”。
4. 系统显示人员姓名、办理人员、开始时间、当前进度和办理结果。
5. 选择“确认提交”后，M01 生成一次同步记录，并依次通知 EDP、M03、M04、M05、M06、M07、M09、M10、M13、M14。
6. 在“办理进度”查看每个系统的“待处理、处理中、已完成、待管理员确认、处理失败”。

## 离职结果

离职人员默认不再出现在“在职人员”名单中，进入“已离职人员”名单。登录、工作办理权限、智能体使用权会被关闭；待分配事项、办公用品、设备、智能体配备等进入交接清单。历史数据保留，只是不再允许用离职身份继续操作。

## 重新入职结果

重新入职只恢复基本人员信息和登录资格。原来的审批权限、业务负责人、智能体配备和设备领用不会自动恢复，必须由管理员在交接清单中逐项确认。

## 失败处理

如果某个系统显示“处理失败”，先打开该系统的处理说明，再点击“重新办理”。重复点击不会重复执行已经完成的动作。如果仍失败，由系统负责人处理；不得直接修改数据库，也不得手工删除同步记录。

## 安全要求

- 只有管理员和总经理可以办理离职或重新入职。
- 申请人不能审批自己的办理。
- 密码、签名、手机号、邮箱和完整留言不得写入日志。
- 未部署的系统会显示“未部署”，不允许进入“已完成”。
- 所有操作保留办理人、审批人、时间、结果和失败说明。
